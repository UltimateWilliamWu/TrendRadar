【美债收益率与AI资本开支共同主导美股定价】
「30年期美债收益率创逾20年新高」「通胀、赤字、AI发债齐施压」与「高盛：五大超大规模云服务商2027年AI基础设施支出将提高54%」共同指向：利率上行并未压制AI资本开支，市场正在重新定价“长久期资产=高估值科技”的折现率风险，同时继续追逐AI算力链的收入确定性。

【资产映射】
美债、美元、纳指/美股成长股、AI算力、光通信、服务器、HBM、网络设备、云厂商。

【传导链条】
美债收益率上行 -> 折现率抬升 -> 高估值成长股承压；但AI capex继续上修 -> 算力/网络/光模块/存储需求维持高景气 -> 相关硬件龙头相对抗跌甚至轮动走强。

【证据强度：强】
2）

【中美互动与风险偏好边际改善，但更多是情绪修复而非基本面反转】
「习近平同美国总统特朗普会谈」「商务部：中美第八轮经贸磋商达成多项共识」提升了风险偏好，利好中概、港股、人民币资产及部分出口链的情绪修复；但当前热度更多来自会晤与表态，缺少足以改变关税、科技限制、资本流动的硬政策落地，因此对定价的影响更偏短线风险溢价回落。

【资产映射】
人民币、港股/中概、A股外需链、跨境互联网、消费电子、航运与出口制造。

【传导链条】
会谈/共识 -> 风险溢价下降 -> 港股与中概估值修复；若后续无具体政策兑现，则涨幅容易回吐。

【证据强度：中】
3）

【能源与地缘对通胀预期的扰动仍在，但边际影响弱于利率主线】
「美国天然气期货跌幅扩大至5%」「布油跌2%/跌超1%」与俄乌相关消息并存，说明能源价格短线波动仍会影响通胀预期和风险资产，但目前更像交易层面的波动，不足以改写宏观主线。对美债、美元、能源股、航空/化工成本端有边际影响。

【资产映射】
原油、天然气、能源股、通胀预期、欧洲化工。

【传导链条】
能源价格回落 -> 通胀压力边际缓和 -> 长端利率上行压力略减；但地缘消息反复 -> 波动率维持高位。

【证据强度：中】
舆论风向争议
【预期差1：AI资本开支是否已进入“过热但仍可交易”的阶段】
热榜大量围绕「AI资本开支冲向1.7万亿美元」「算力增10倍」「内存和HDD短缺可能持续5年以上」展开，情绪上偏向“AI继续无脑扩张”。但硬信息里同时出现「融资需求上升以及基础设施限制可能拖累未来支出增长速度」「回报要达到什么水平才算合理」以及「目前尚未看到人工智能对生产率的影响」。这意味着：市场对AI链的交易拥挤度高，证据更强的一侧是“capex继续增长”，证据较弱的一侧是“利润兑现速度”。短线可能过度交易的是纯主题弹性，未充分定价的是供给瓶颈对上游硬件的持续支撑。

【预期差2：美债收益率上行是否会压垮美股】
热榜强调「美债抛售加剧」「30年期收益率创逾20年新高」，但盘面同时出现「美股期货上涨」「债市抛售暂歇」「Meta涨超4%」。说明市场并未简单按“利率上行=风险资产全面崩”的线性逻辑交易，而是在区分：现金流更近、AI叙事更强、回购更强的公司更抗压。证据更强的是利率上行事实，证据更弱的是“美股系统性失速”。

【预期差3：中美会谈的定价可能偏情绪化】
热榜对「习近平同美国总统特朗普会谈」高度聚焦，但目前可见信息主要是会谈、祝酒辞、欢迎宴会等软信息，缺少明确的关税、科技、金融开放条款。若市场已提前交易“关系显著缓和”，则存在过度乐观风险；若仅交易短线风险偏好修复，则仍有一定空间。证据更强的是会晤本身，证据不足的是政策实质改善。
