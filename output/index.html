投资相关性：高。

【市场主线1｜全球AI/算力链进入“融资与回报”再定价阶段】
热榜与美股收盘共同指向：市场不再只交易AI资本开支扩张，而是在重新评估“谁能把算力投入转化为现金流/订单”。美股半导体、存储、光模块大幅回落，纳指重挫；同时热榜出现「AI融资担忧」「AI信用风险」「AI崩盘推演」等叙事，说明风险偏好从高估值成长切向“盈利兑现/现金流安全”。传导链条：AI融资与回报不确定性上升 -> 美股科技估值压缩、信用利差担忧 -> 全球AI链情绪降温 -> A股/港股算力硬件、CPO、存储、光模块先跌后修复，波动加大。

【证据强度：强】
主要影响资产：美股纳指、费城半导体、A股/港股算力硬件、CPO、存储、光模块、AI软件与云相关标的。\n

【市场主线2｜中国权益市场午后“V型修复”，风格从高波动成长切向大金融+权重+主题轮动】
A股早盘大幅下挫后午后翻红，创业板、深成指修复明显，沪指跌幅收窄；同时银行板块逆势回落，白酒、保险、券商、零售、大金融、互联网金融、创业板权重股、宁德时代等共同拉升，说明资金在做“指数稳定+高弹性修复”的风格切换。传导链条：早盘风险偏好受外盘AI抛售拖累 -> 午后资金回补权重与高流动性标的 -> 宽基ETF成交放大、指数快速修复 -> 市场短线从单边避险转向结构性博弈。

【证据强度：强】
主要影响资产：A股创业板、深成指、沪指、沪深300ETF、创业板ETF、港股恒科指及高权重科技/消费/金融。\n

【市场主线3｜机器人、半导体、光刻机等国产科技主题继续获得交易拥挤度，但更偏情绪驱动】
A股人形机器人、半导体、光刻机、CPO午后冲高，叠加「宇树科技」「具身智能」等热词，说明资金在AI主线回撤后寻找新的高弹性替代方向；但当前更多是题材轮动而非基本面新证据。传导链条：AI主线波动 -> 资金寻找低位高弹性主题 -> 机器人/半导体/光刻机短线拥挤度上升 -> 相关中小盘与概念股波动放大。

【证据强度：中】
主要影响资产：A股机器人、半导体设备/材料、光刻机、国产算力链、部分中小市值题材股。整体判断：今天真正影响定价的是“全球AI估值再定价”与“中国权益风格修复/轮动”，其余多为情绪扩散。
