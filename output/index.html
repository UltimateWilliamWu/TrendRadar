【市场主线1】

【：中国7月外贸数据超预期，强化“出口韧性+高技术制造出海”定价】
- 事件：海关数据显示「中国7月出口同比增24%，高技术产品出口增长超五成」，同时「7月集成电路出口金额达387.4亿美元；1-7月累计出口金额达2160亿美元，同比增长99.5%」，汽车出口、钢材出口维持高位。
- 传导链条：出口韧性/高技术产品放量 -> 制造业外需与产业链景气预期上修 -> 半导体设备/材料、PCB、光通信、汽车零部件、工业自动化等板块风险偏好抬升 -> A股成长风格占优、港股科技与制造链跟涨。
- 主要影响资产/市场：A股创业板、科创50、港股科技/制造链、人民币汇率、出口链相关商品与航运预期。
- 证据强度：强（海关总署/官方数据）。

【市场主线2】

【：AI算力与半导体硬件继续成为全球定价锚，叠加HBM/存储/先进封装供需紧张】
- 事件：热榜与RSS集中指向「英伟达拟下调Rubin Ultra的HBM配置，应对高端HBM短缺」、「美光管理层传递强势信号」、「存储芯片板块震荡上扬」、「腾讯阿里押注NPO明年迈向商用 先进光互联多路线竞速」、「国家能源局：加大关键电力装备自主研发 推动电力芯片、特高压组部件等关键技术突破」。
- 传导链条：AI训练/推理需求持续扩张 -> HBM、存储、先进封装、光互联、电力与散热基础设施供给偏紧 -> 上游材料/设备/PCB/光模块/电力芯片订单与议价能力改善 -> 中美科技股中算力硬件、存储、半导体设备材料、数据中心基础设施受益。
- 主要影响资产/市场：美股半导体、A股算力硬件/PCB/存储/半导体设备、港股AI概念与大模型概念、波动率与成长风格。
- 证据强度：中到强（英伟达/美光为专业媒体报道，国家能源局为官方口径；但部分细节仍需财报或公司披露验证）。

【市场主线3】

【：美联储路径与全球长端利率再定价，叠加中东地缘推升油价，影响风险偏好与风格切换】
- 事件：市场热榜集中在「沃什被曝为9月加息敞开大门」「若未来几周通胀数据强劲，沃什将准备在9月加息」「美银CEO：美联储年内或连加三次息」「美国非农报告今晚登场」，同时「霍尔木兹海峡博弈升级油价跳涨」「原油走强、黄金微跌」「全球长端利率见顶信号？」。
- 传导链条：非农/通胀与美联储表态 -> 美债收益率与美元波动 -> 全球成长股估值折现率变化 -> 美股科技、A股/港股高估值成长风格承压或分化；地缘冲突推升油价 -> 能源、航运、航空、化工成本与通胀预期再定价。
- 主要影响资产/市场：美债、美元、黄金、原油、A股/港股成长风格、航空/能源/贵金属。
- 证据强度：中（政策表态与市场传闻混合，非农为关键验证点）。
舆论风向争议
【预期差1：AI硬件与存储是否只是情绪过热，还是供需真紧】
- 热榜情绪：英伟达、存储芯片、CPO、PCB、光互联、AI大模型概念全面活跃，A股创业板与港股AI概念同步走强。
- 硬信息：英伟达HBM配置调整、美光管理层强势表态、存储股在美股先跌后分化、A股存储与PCB同步放量。
- 判断：短线交易拥挤度高，但供给约束与AI资本开支扩张的证据更强，暂不宜简单视为纯题材；真正的分歧在于“业绩兑现速度”而非“需求是否存在”。
- 证据强度：中到强。

【预期差2：出口韧性被低估，但对指数的边际拉动可能弱于对结构的拉动】
- 热榜容易把「中国7月出口同比增24%」解读为全面景气回升。
- 但数据结构更像“高技术制造与部分出海链条强，内需与部分大宗进口仍分化”，例如原油进口同比下降、手机出口回落、进口增速放缓。
- 判断：对指数层面是温和利好，对结构层面更利好半导体设备、PCB、汽车出口链、光通信、稀土与高端制造；对传统内需链的传导有限。
- 证据强度：强。

【预期差3：光伏关税与硅料自律，利好并不等于行业反转】
- 热榜有「多家光伏龙头回应美国加征关税」「光伏硅料八巨头签署倡议：不得低于成本价销售」。
- 这说明行业仍处于政策/价格自律修复阶段，但需求端与海外贸易摩擦仍在，更多是缓解恶性竞争，不足以直接推导为全面反转。
- 判断：短线情绪可能过热，真正可交易的是供给侧出清与价格纪律改善，而不是单次倡议本身。
- 证据强度：中。

【预期差4：宇树IPO是情绪锚，不是宏观主线】
- 热度极高，但对大盘定价影响主要体现在机器人/具身智能、一级市场估值锚与相关概念股情绪，不应上升为宏观主线。
- 证据强度：中（发行价与配售信息较明确，但对二级市场传导仍偏情绪）。
