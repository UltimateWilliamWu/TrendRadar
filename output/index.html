【主线一：AI算力硬件继续是A股最强定价主线，且从情绪修复转向业绩/订单验证】

- 传导链条：AI资本开支预期上修 -> 光模块/交换机/服务器/PCB等算力硬件订单与盈利预期抬升 -> 创业板、科创板及高弹性成长风格占优 -> 价格影响偏正面，且更偏向龙头集中度提升。
- 主要影响资产/市场：A股创业板、科创板、港股科网/硬科技、美股AI链情绪；细分方向包括光模块、AI服务器、PCB、液冷、半导体设备。
- 风险提示：若后续没有新增订单、指引或海外云厂商CAPEX再确认，当前更多是高拥挤度下的趋势交易。
2）

【主线二：华为高性能芯片与三折叠手机带动国产替代与高端消费电子情绪，但更偏主题催化而非基本面拐点】
- 证据强度：中
- 事件：多条热榜集中指向“华为时隔六年再次发布高性能芯片”“华为最新三折叠售价19999元起”“华为首款‘韬定律’逻辑折叠芯片手机来了”。
- 传导链条：国产高端芯片/终端发布 -> 市场强化对国产供应链、先进封装、射频/存储/显示/铰链等环节的替代预期 -> 相关A股硬科技与消费电子链条获得情绪溢价 -> 价格影响偏正面，但持续性取决于量产、良率与供应链可验证性。
- 主要影响资产/市场：A股半导体、消费电子、先进封装、折叠屏产业链；港股相关硬科技与华为链。
- 风险提示：当前热度高于可验证订单，若缺少官方披露的出货/供应链受益名单，容易从“事件驱动”回落为“情绪交易”。
3）

【主线三：汇率与避险资产在东亚与中东地缘扰动下重新定价，黄金、日元、油价是更直接的宏观锚】

- 传导链条：地缘风险与汇率政策预期 -> 美元/日元波动加大、原油风险溢价抬升、黄金避险需求增强 -> 全球风险偏好边际受压，资源与避险资产相对占优 -> 对A股/港股成长风格形成估值扰动，对黄金、油气、军工及部分出口链形成支撑。
- 主要影响资产/市场：黄金、原油、美元/日元、人民币资产风险偏好、港股科网与高估值成长。
- 风险提示：若地缘消息未进一步升级，油价与避险资产的脉冲可能较快回吐；日元波动更可能影响全球套息交易而非单一市场基本面。
