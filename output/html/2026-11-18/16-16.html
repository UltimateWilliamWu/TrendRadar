核心热点态势
投资相关性：高。

【市场主线1：英伟达财报继续强化AI资本开支链条，但市场开始从“无限扩张”切换到“更挑剔的扩张”】

【证据强度：强】
来自英伟达财报/电话会与多家专业媒体摘要：本季指引再超预期、下财年指引上调、Vera Rubin“爆发式开局”，同时电话会强调AI投资将更加“克制与挑剔”。这意味着市场定价不再只是“AI需求强”，而是进一步交易“谁能拿到更高质量的AI预算、谁的回报率更可验证”。
传导链条：英伟达业绩超预期 -> AI算力需求预期维持高位 -> 服务器、HBM、光模块、先进封装、半导体设备链条情绪修复 -> 但资本开支筛选更严，边际上利好龙头、压制纯概念和高估值二线。
主要影响资产/市场：美股AI龙头、A股/港股算力硬件、算力租赁、半导体设备、光通信；同时对美债收益率、美元风险偏好、黄金形成间接影响。

【市场主线2：中美科技与半导体摩擦再度升温，H200对华供应受限强化国产替代与供应链重估】

【证据强度：强】
热榜与RSS均指向“英伟达停止向中国供应H200芯片，外交部回应”，属于明确的政策/供应链事件，不是情绪噪音。对中国市场而言，这会强化国产算力、国产GPU、服务器、AI基础设施、半导体设备与材料的替代预期；对海外则意味着中国市场收入敞口较高的美股半导体公司面临增量不确定性。
传导链条：出口限制/供应受限 -> 中国AI算力供给约束上升 -> 国产替代与本土算力投资预期升温 -> A股科创、算力硬件、华为算力、半导体设备相对占优；同时海外半导体龙头在中国收入预期上承压。
主要影响资产/市场：A股科创50、半导体设备、算力租赁、华为链；美股英伟达及其中国相关收入预期；港股科技风格也会受风险偏好影响。

【市场主线3：全球利率与汇率的边际扰动仍在，美元偏强、部分新兴市场被迫防守】

【证据强度：中-强】
印尼央行意外加息25bp、强调继续干预外汇市场；英国CPI后利率期货显示英国央行12月加息概率回落但仍高；马来西亚林吉特走弱、印尼盾小幅承压。说明当前全球定价里仍有“美元偏强/非美货币承压/新兴市场防守”的成分。
传导链条：美国利率预期偏鹰 + 美元偏强 -> 新兴市场汇率承压 -> 相关央行被迫加息或干预 -> 全球流动性边际收紧 -> 对高估值成长、商品和风险资产形成压制；但对美元资产、短久期现金流资产相对有利。
主要影响资产/市场：美元、非美货币、新兴市场债券与汇率、黄金、原油、全球成长股估值；对A股/港股的影响主要通过风险偏好和北向/南向资金预期传导。
舆论风向争议
【预期差1：英伟达财报极强，但市场并未简单转为“全面看多AI”】
热榜情绪很热，容易把“财报超预期”直接等同于AI板块普涨；但硬信息显示管理层同时强调“AI投资更克制与挑剔”，高盛也提示要平衡生态输血与股东回报。说明市场真正交易的是“AI资本开支质量分化”，不是无差别追涨。证据更强的一侧是公司披露与专业媒体摘要。

【预期差2：H200对华限制不是新故事，但对A股算力/国产替代的边际催化仍然有效】
这类消息在舆论上容易被视为“老题材反复炒作”，但本次与英伟达财报、电话会、外交部回应同时出现，说明它仍是可交易的边际变量。若后续国产算力订单、设备招标、服务器出货验证跟上，市场会把它从情绪题材升级为基本面题材。证据强度目前偏强，但对业绩兑现的证据仍不足。

【预期差3：全球利率并非单边宽松，部分市场的“降息交易”可能过度】
印尼意外加息、英国加息预期仍在，说明全球并非一致转向宽松。热榜里对“央行加息/干预”的关注度高，但真正影响资产定价的是美元强势与非美货币防守，这对黄金、商品和新兴市场风险资产的边际压制可能被低估。证据强度中等偏强。

【预期差4：A股盘面修复并不等于全面风险偏好回升】
A股收盘显示科创50明显强于大盘，但成交仅1.38万亿，中证1000偏弱，说明资金更偏向少数高景气方向，广谱风险偏好并未全面恢复。热榜里“算力租赁、华为算力”很热，但更像结构性轮动而非全面牛市确认。证据强度中等。
